## 🛠️ Key Concepts Learned

### 🎨 Styling & Typography
- **Colors:** Text, background, and border colors.
- **Typography:** Font sizes, weights, uppercase, and underlines.
- **Borders:** Width, colors, and border-radius (rounded corners).

### 📐 Layout & Spacing
- **Box Model:** Mastering Padding (p) and Margin (m).
- **Sizing:** Width (w), Height (h), Viewport (vw/vh), and Max/Min constraints.
- **Flexbox:** `flex`, `justify-center`, `items-center`, `space-between`.
- **CSS Grid:** `grid-cols`, `grid-rows`, and `grid-span`.

### 📱 Responsive Design
- Building layouts that change based on screen size (sm, md, lg, xl).
- Mastering the mobile-first approach.
